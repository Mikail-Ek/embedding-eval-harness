Ragas is an evaluation framework built specifically for large language model applications such as Retrieval-Augmented Generation systems. Because the answers produced by these systems are natural language rather than simple right-or-wrong outputs, Ragas breaks quality down into several distinct, measurable dimensions, each targeting a different way a RAG system might fail.

Two of these metrics evaluate the retrieval side of a system. Context Precision checks whether the documents that were retrieved and ranked near the top were actually relevant, rather than being buried below irrelevant results. Context Recall checks whether all of the relevant information that existed was actually retrieved, rather than only some of it being found.

Two further metrics evaluate the generation side of a system. Faithfulness checks whether the answer produced by the language model only makes claims that are genuinely supported by the retrieved context, which serves as a direct check against hallucination. Response Relevancy checks whether the answer actually addresses the question that was asked, regardless of whether the answer happens to be factually correct.

To actually run an evaluation, Ragas needs realistic test data, meaning a set of questions along with the retrieved context and generated answers for each one. This test data can come from an existing public dataset, or it can be generated synthetically. Ragas provides its own synthetic test set generator, which builds a knowledge graph from a set of source documents and then uses a language model to automatically generate realistic question and answer pairs based on that graph, including harder questions that require connecting information across multiple documents.
